# Nova Raiders

Tarayıcıda çalışan, üçüncü şahıs nişancı oyun prototipi.

## Çalıştırma

GitHub Pages'i etkinleştirin veya `index.html` dosyasını statik bir sunucuda açın:

```bash
python3 -m http.server 8080
```

Ardından `http://localhost:8080` adresine gidin.

## Kontroller

- **WASD** — Hareket
- **Fare** — Bakış
- **Sol Tık** — Ateş
- **Boşluk** — Zıpla
- **Shift** — Koş
- **R** — Şarjör

## Not

Bu proje Three.js kullanır ve internet bağlantısı gerektiren CDN üzerinden yüklenir.
